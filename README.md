# Частотний аналіз літер

Навчальний проєкт із дисципліни «Професійна практика програмної інженерії» (варіант 7, лабораторні роботи № 1–3).
Поточна версія: **0.1.17**.

Консольна утиліта на Python, яка підраховує частоту кожної літери в тексті без урахування регістру та виводить наочну стовпчикову діаграму в консоль. У підсумку відображається точна кількість входжень кожної літери, загальна кількість літер у тексті та кількість унікальних символів.

## Вимоги та запуск

Для роботи потрібен **Python 3.10+**. Проєкт використовує лише стандартну бібліотеку Python і не потребує встановлення сторонніх пакетів з PyPI.

### Інтерактивний запуск (ввід із консолі)

```text
python main.py
Введіть текст: Абба! 123
Літера | Діаграма (максимум 50 символів; поріг: 1) | Кількість
а ################################################## 2
б ################################################## 2
Усього літер: 4; різних: 2
```

### Фільтрація за мінімальним порогом частоти (`--min-count`)

Параметр `--min-count N` (де `N` — ціле число від 1, за замовчуванням `1`) дозволяє виводити на діаграму лише ті літери, які зустрічаються в тексті не менше `N` разів. Загальна статистика початкового тексту при цьому зберігається:

```text
python main.py --min-count 2
Введіть текст: ааааббв
Літера | Діаграма (максимум 50 символів; поріг: 2) | Кількість
а ################################################## 4
б ######################### 2
Усього літер: 7; різних: 3
Показано різних літер: 2; поріг: 2.
```

### Вибір стилю діаграми (`--chart-style`)

За замовчуванням використовується текстовий режим `ascii` (символи `#`). У межах ЛР3 додано режим `blocks`, який будує псевдографічну стовпчикову діаграму за допомогою підключеного модуля `zanalyze`:

```text
python main.py --chart-style blocks --min-count 2
```

### Читання тексту з файлу (`--file`)

```text
python main.py --file text.txt
python main.py --file text.txt --min-count 3 --chart-style blocks
```

Підтримуються багаторядкові текстові файли у кодуванні **UTF-8** (зокрема з BOM).  
Переглянути довідку за параметрами: `python main.py --help`.

## Особливості реалізації

- **Робота з Unicode:** вхідний текст нормалізується за стандартом Unicode NFC, щоб складені символи (наприклад, літера з окремим діакритичним знаком) коректно об’єднувалися в один символ.
- **Фільтрація символів:** підраховуються всі літери алфавітів (включно з українськими `ґ`, `є`, `і`, `ї`), тоді як пробіли, цифри та розділові знаки ігноруються. Візуально схожі літери з різних абеток (наприклад, латинська `a` та кирилична `а`) рахуються окремо.
- **Пропорційне масштабування (`scaling.scale_bars`):** найдовший стовпчик діаграми у режимі `ascii` завжди масштабується до 50 символів `#`, а решта розраховуються пропорційно за точною цілочисловою формулою з округленням половини вгору (`half-up`); будь-яка видима літера отримує щонайменше один символ `#`.
- **Відбір за порогом:** якщо заданий поріг `--min-count` перевищує частоту всіх літер у тексті, програма виводить повідомлення про відсутність збігів, зберігає загальні підсумки початкового тексту і штатно завершується з кодом `0`.
- **Обробка помилок:** при порожньому вводі, відсутності літер у тексті, неіснуючому файлі, некоректному кодуванні або хибному значенні порога (`0`, від’ємне чи неціле число) виводиться зрозуміле повідомлення в `stderr` без системного traceback, а програма завершується з кодом `2`.

## Тестування

Для перевірки синтаксису та запуску модульних тестів використовується стандартний модуль `unittest`:

```text
python -m py_compile main.py scaling.py
python -m unittest -v
```

Тестовий набір налічує **34 автотести** (26 базових тестів із ЛР1–2 у `test_main.py` та 8 нових межових й інтеграційних тестів із ЛР3 у `test_lr3.py`), які покривають роботу з регістром, українською абеткою, нормалізацію Unicode, змішані абетки, пропорційне масштабування (зокрема округлення на точній половині), порогову фільтрацію, виклик стороннього рендерера `blocks`, читання UTF-8 файлів та обробку помилок вводу.

## Ліцензія та походження коду (ЛР3)

Власні напрацювання в проєкті поширюються на умовах ліцензії **zlib** (повний текст наведено у файлі [LICENSE](LICENSE)). Вона дозволяє вільне повторне використання навчальної утиліти за умови збереження інформації про походження та без надання гарантій.

Для режиму `--chart-style blocks` інтегровано функції `_bar` та `print_histogram` із проєкту [zlib-ng/zanalyze](https://github.com/zlib-ng/zanalyze/tree/4cc0b3fd286c2db5ec4fdc1d2637eaab2b0ed515) (автор — **Hans Kristian Rosbach**), який також поширюється під ліцензією **zlib**. Оригінальне повідомлення про авторські права та умови ліцензії збережено у файлі [`vendor/zanalyze_histogram.py`](vendor/zanalyze_histogram.py) та в окремій копії [`LICENSES/zanalyze-zlib.txt`](LICENSES/zanalyze-zlib.txt). Сам файл у `vendor/` явно позначено як витяг (змінену дистрибуцію), тож вимоги ліцензії zlib для власного та стороннього коду виконуються одночасно.

Детальна таблиця походження всіх модулів проєкту наведена у файлі [АТРИБУЦІЯ.md](АТРИБУЦІЯ.md).

  - [Issue #2](https://github.com/st1ksi/letter-frequency-labs/issues/2) та [PR #4](https://github.com/st1ksi/letter-frequency-labs/pull/4) (гілка `lr2-frequency-threshold`) — фільтрація літер за мінімальним порогом частоти `--min-count`.
