Побачте частоту літер у тексті

Введіть рядок або відкрийте текстовий файл UTF-8. Програма порахує літери, об’єднає великі й малі та покаже діаграму. Цифри, пробіли й розділові знаки не враховуються.

Завантажити v1.0.0 для Windows x64

У ZIP — готова програма з вбудованим середовищем виконання. Встановлювати Python або редактор коду не потрібно. Розпакуйте весь архів у власну папку; запускайте EXE через консоль, щоб результат залишався на екрані.

Перший запуск

letter-frequency.exe
Введіть текст: Абба! 123
а ################################################## 2
б ################################################## 2
Усього літер: 4; різних: 2

Текст показано зі скороченим службовим заголовком; частоти точні, найбільший стовпчик має 50 символів.

Файл та фільтр

letter-frequency.exe --file sample.txt
letter-frequency.exe --file sample.txt --min-count 2
letter-frequency.exe --file sample.txt --chart-style blocks

Поріг включний: за --min-count 2 видно літери з частотою від двох, а загальні підсумки стосуються початкового тексту. Режим blocks будує діаграму блоками Unicode.

Якщо дані не підходять

Порожній файл або текст без літер викликає зрозуміле повідомлення про помилку, код завершення — 2. Файл іншого кодування потрібно зберегти у UTF-8. Великі й малі літери рахуються разом; схожі літери різних абеток залишаються різними.
